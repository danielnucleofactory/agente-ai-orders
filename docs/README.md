# Documentación del Proyecto OLO Raga Orders

Bienvenido a la documentación central de OLO Raga Orders. Este directorio contiene toda la información necesaria para entender, operar, mantener y extender el proyecto.

## Estructura

La documentación está organizada en las siguientes secciones principales:

- **[/docs/api](./api/REFERENCE.md):**
  - **Referencia de la API y Mapeo de Campos.** Contiene la documentación exhaustiva de cada endpoint, incluyendo ejemplos de código, y el mapeo detallado de los campos desde la base de datos hasta el frontend. Es la fuente de verdad para cualquier integración.

- **[/docs/architecture](./architecture/DATA_MODEL.md):**
  - **Arquitectura y Modelo de Datos.** Describe las decisiones de alto nivel, el flujo de datos y la estructura de la base de datos. Esencial para entender cómo funciona el sistema internamente.

- **[/docs/guides](./guides/PROMPT_UPDATE_DOCS.md):**
  - **Guías y Procedimientos.** Contiene tutoriales y documentos de procedimientos, incluyendo:
    - [Guía para Actualizar Documentación](./guides/PROMPT_UPDATE_DOCS.md) - Mantener documentación sincronizada con IA
    - [Guías de Desarrollo con IA](./guides/AI_DEVELOPMENT_GUIDELINES.md) - Mejores prácticas para desarrollo asistido por IA
    - [Mejores Prácticas del Proyecto](./guides/PROJECT_BEST_PRACTICES.md) - Guía completa de mejores prácticas de desarrollo

- **[/docs/SUPPORT_EMAIL_SYSTEM.md](./SUPPORT_EMAIL_SYSTEM.md):**
  - **Sistema de Envío de Correos con CC.** Documentación completa del sistema de notificaciones por correo electrónico que envía un único correo a soporte con copia (CC) al usuario y administrador. Incluye configuración, uso, tests y personalización.

## Cómo Mantener la Documentación
Para asegurar que esta documentación se mantenga siempre sincronizada con el código, por favor sigue las instrucciones en la [**Guía para Actualizar la Documentación**](./guides/PROMPT_UPDATE_DOCS.md).
